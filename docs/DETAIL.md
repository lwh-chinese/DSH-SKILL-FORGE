# 技能管理器 / Skill manager

在 DSH 左侧栏新增「技能」入口，打开一个管理面板，用于维护已安装的 skill。

功能：

- 列出所有已安装的 skill，来源覆盖磁盘根目录（项目 `.dsh/skills`、`.agents/skills`，用户 DSH/agents `skills`，自定义目录，含目录联接/符号链接）以及 DSH 内置的 bundled/运行时 skill，显示名称、描述、来源与启用状态。顶部可按名称/描述/来源筛选，并显示总数、可见、隐藏计数。
- 查看某个 skill 的 `SKILL.md` 正文与 frontmatter，并可一键复制其绝对路径。
- 通过切换 frontmatter 中 DSH 原生的 `disable-model-invocation` 字段控制 skill 对模型的可见性（不影响原始指令正文，且不会破坏其它复杂 YAML 字段）。
- 在用户技能根目录新建 skill（目录式 `<name>/SKILL.md`），或删除已有 skill。
- 安装时声明 **「制作 skill」预设模式**（`preset-make-skill`）：新建会话可选，以「skill 创作者」人设启动，挂载文件读写、文件搜索、skill 文件系统与 skill 加载工具，专门用于创建、编辑和维护 skill。
- 在对话里 `@` 指定 skill：向输入框注册一个 `@` 候选项源，`@` 后先出现一个 **「技能」大类**，按 Tab 或点箭头进入后原位展开全部对模型可见的 skill，带面包屑与实时筛选；直接接着输名字（如 `@pdf`）也能就地补全。选中后插入 `/skillName `，由 DSH 原生 skill 工具在发送时注入完整正文（带 60 秒本地缓存）。
- 在「+」菜单里选 skill：注册 `/skills` 命令贡献，输入框旁的「+」菜单中多出「选择一个技能」，打开带模糊搜索的二级选择器，选中后把 `/skillName ` 插入当前草稿（已有内容则追加）。
- GitHub 搜索新建：点顶部「从 GitHub 搜索」，按关键词搜索公开仓库（结果缓存 5 分钟）。每条结果有三个操作：**在 GitHub 打开**（在系统浏览器或右侧栏打开仓库原网页）、**直接安装**（把仓库里的 `SKILL.md` 下载到可写技能目录，无需浏览器或新会话）、**采用**（跳转到「制作 skill」预设模式的新会话，并把仓库信息作为调研上下文预填）；也可直接用关键词进入制作模式。
- 提示词增强：跳转前会尝试用本机已配置的模型（`ctx.llm` 第一个可用 provider/model）把草稿指令改写得更具体；若没有可用模型、余额不足、超时或报错，则保留原提示词并照常跳转。

兼容性：

- 所有服务访问使用软获取与 try/catch，缺少某个槽位或服务时优雅降级，不影响其他插件。「+」菜单的 `/skills` 贡献通过 `ctx.inject(['commandUi'])` 注册，等待依赖就绪，加载顺序不会导致静默丢失。
- 使用宿主主题变量与 React 模块表，不打包任何 DSH Client 内部包。
- 管理 API 由本插件自己的 `webServer` 前缀路由提供，不依赖 Typert 代码生成或跨包 Remote。
- 该路由在处理请求前调用 `connection.requestRejection(request)` 接入宿主准入检查（宿主/Origin 校验 + 已认证 Peer）；没有 `connection` 服务的旧宿主自动跳过，保持兼容。浏览器面板的同源请求携带已签名 Cookie，正常放行。

限制：在面板中以只读方式预览 skill 正文；编辑正文请使用你熟悉的文件工具直接修改 `SKILL.md`，面板会自动反映改动。
